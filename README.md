# OtherWise relay

Staging area for the [OtherWise](https://www.youtube.com/@otherwisedaily) daily Shorts pipeline.

Each day a rendered MP4 is attached here as a release asset, just long enough for the
upload step to fetch it and publish to YouTube. `_published.md` is the authoritative
log of what has already been made, so topics are never repeated.

Nothing here is meant to be watched directly — the videos live on the channel.
